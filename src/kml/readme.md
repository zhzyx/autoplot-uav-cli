# DJI KML Python API

This project provides a Python API for working with KML files generated by DJI drones. It simplifies the process of parsing, analyzing, and manipulating KML data for drone flight planning and data visualization.

## Features

- Parse DJI-generated KML files.
- Extract flight paths, waypoints, and metadata.
- Create, modify or export KML files.
- TODO: Integrate with mapping libraries for visualization.
